# Agent instructions

## Documentation

Write project documentation and other project text according to the `project-docs` skill, within the scope defined by that skill. Before the first code change or writing documentation, code comments, commit messages, pull requests, release notes or other project text in each session, read the full specification. Use the locally installed `project-docs` skill when available; otherwise read https://raw.githubusercontent.com/PosvdM/Skills/main/skills/project-docs/SKILL.md . If neither source is accessible, tell the user.
